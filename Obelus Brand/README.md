# Obelus Brand Package

Version 1.0 - August 2026

This folder is the complete Obelus identity system for product, web, motion, and everyday brand applications. Start with `00 Start Here/START_HERE.md`, then use the offline interactive guide or PDF in `08 Brand Guidelines`.

## Core identity

- Brand idea: Constructive skepticism
- Category: Live verification for spoken conversations
- Master tagline: Evidence at conversation speed.
- Primary mark: Dialogue Axis - a custom obelus whose two points suggest independent checks around a claim
- Primary typeface: Instrument Sans
- Utility typeface: IBM Plex Mono
- Primary color: Evidence Blue `#3B50E0`

## Folder map

- `00 Start Here` - orientation and launch notes
- `01 Strategy` - positioning, audience, pillars, messaging, voice, and tagline system
- `02 Logos` - master artwork, lockups, monochrome versions, app icons, favicons, PNG ladders, and explorations
- `03 Typography` - font files, licenses, type rules, and specimen artwork
- `04 Color` - palette, semantic colors, accessibility guidance, and contrast matrix
- `05 Graphic System` - patterns and status-icon system
- `06 Motion` - five loaders, implementation code, Lottie, SVG, GIF, MP4, WebM, posters, and accessibility rules
- `07 UI and Layouts` - layout rules, design tokens, live landing/product demos, screenshots, and application templates
- `08 Brand Guidelines` - complete PDF, quick reference PDF, and interactive offline guide
- `09 Previews` - presentation-ready overview sheets
- `10 Legal and Licenses` - source notes, font licensing, and naming-clearance warning
- `99 Source` - reproducible asset generators and machine-readable brand specification

## Usage notes

- Use supplied SVG artwork rather than a typed division glyph.
- Pair every verification state with text and an icon; color is never the only signal.
- Loading motion is neutral. Verdict colors appear only after a result exists.
- Preserve editable source SVGs and export derivatives from them.
- Review `10 Legal and Licenses/Naming and Trademark Note.md` before public launch.

`FILE_MANIFEST.csv` inventories the final package and `SHA256SUMS.txt` verifies file integrity.
