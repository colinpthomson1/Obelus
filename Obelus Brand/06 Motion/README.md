# Obelus Loading Animations

Open `index.html` to preview all five loaders offline.

Each loader folder contains:

- An animated inline-ready SVG
- A static poster SVG and PNG
- A Lottie JSON file
- A small implementation stylesheet
- An offline HTML example
- GIF, MP4, and WebM preview renders
- A short usage note

Use SVG/CSS for normal web and software implementation. Treat video and GIF files as review or presentation formats. Read `Motion System.md` for accessibility, timing, and semantic guidance.

`React/ObelusLoader.tsx` provides a typed reference component. `Tokens` contains the shared CSS and JSON motion values.
