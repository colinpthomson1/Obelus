# Typography System

## Primary family: Instrument Sans

Instrument Sans is precise with subtle playfulness, matching the central brand balance. Its variable weight and width axes allow the system to feel expressive on landing pages and disciplined inside the product without introducing a second sans-serif family.

Use the width axis at 92–96 for large display type and 100 for product UI and body copy.

## Functional companion: IBM Plex Mono

IBM Plex Mono is reserved for timestamps, source identifiers, transcript timing, versions, and compact research metadata. It is never the default for evidence, explanations, or long reading.

Both families are freely distributable under the SIL Open Font License 1.1. Original licenses are included with the font files.

## Scale

Marketing uses fluid display sizes with fixed body text. Product UI uses fixed sizes for spatial predictability.

- Display XL: clamp(4rem, 7vw, 5.5rem)
- Display L: clamp(3rem, 5vw, 4.25rem)
- Heading 1: 2.5rem
- Heading 2: 2rem
- Heading 3: 1.5rem
- Lead: 1.25rem
- Body: 1rem
- Small: 0.875rem
- Metadata: 0.75rem

## Rules

- Use sentence case, including buttons and navigation.
- Use tabular numerals for timestamps, durations, counts, and confidence values.
- Keep long-form measure between 55 and 70 characters.
- Do not use body type below 16 px.
- Do not use more than three weights in a single composition.
- Avoid all caps except short technical labels and never use it for full headlines.
- Do not use monospace as shorthand for “technical.” Its role is functional and narrow.
