# Obelus governance

Obelus is currently a maintainer-led project. The maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md) are responsible for product direction,
technical decisions, security response, releases, and repository
administration.

## How decisions are made

Routine decisions are made in issues and pull requests. Material changes to
architecture, compatibility, privacy, provider identity, hosted-service
boundaries, or release destinations should be proposed publicly before
implementation unless they are urgent security fixes.

Maintainers weigh:

- user safety and explicit consent;
- compatibility with existing Goose-derived interfaces;
- clear separation between the public client and private managed services;
- evidence-led product behavior and calibrated claims;
- maintainability, verification quality, and reversibility.

The final decision rests with the Obelus maintainers. Decisions inherited from
the upstream Goose project are not automatically decisions for Obelus.

## Upstream relationship

Obelus is derived from Goose and continues to preserve appropriate attribution
and selected compatibility interfaces. Goose maintainers do not govern Obelus,
and Obelus maintainers do not speak for Goose or the Agentic AI Foundation.
Changes intended for upstream contribution must follow the upstream project's
own governance and contribution process.

Changes to this document are made through a pull request.
